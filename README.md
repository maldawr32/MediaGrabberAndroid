# MediaGrabber Android

تطبيق Android أصلي بلغة Java لتنزيل وتحويل الوسائط المسموح لك بحفظها. يدعم Android 11 فأعلى (`minSdk 30`) ويستهدف Android 16 (`targetSdk 36`).

## الميزات

- تنزيل فيديو MP4 بجودة: الأفضل، 1080p، 720p أو 480p.
- استخراج الصوت MP3 أو WAV.
- إنشاء GIF لمقطع لا يتجاوز 60 ثانية.
- قص المقطع بتحديد وقت البداية والنهاية.
- تنزيل في Foreground Service مع إشعار تقدم وإمكانية الإلغاء.
- تصدير آمن إلى `Downloads/MediaGrabber` باستخدام MediaStore، من دون صلاحية إدارة جميع الملفات.
- استقبال الروابط من قائمة المشاركة في تطبيقات Android.
- زر لتحديث محرك `yt-dlp` عند تغيّر المواقع.

## البناء في Android Studio

1. افتح مجلد المشروع في Android Studio حديث.
2. اقبل تنزيل Android SDK 36 وBuild Tools 36.0.0 إن طُلب.
3. شغّل `app` على هاتف Android 11 أو أحدث.
4. لإنشاء APK: من القائمة اختر **Build > Build APK(s)**.

أو من الطرفية بعد تثبيت Gradle 9.4.1:

```bash
gradle assembleDebug
```

لا يتضمن الأرشيف ملف `gradle-wrapper.jar` الثنائي؛ لذلك أسهل طريقتين للبناء هما Android Studio أو GitHub Actions المرفق.

سيكون الملف في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## البناء التلقائي عبر GitHub

ارفع المشروع إلى مستودع GitHub ثم افتح تبويب **Actions** وشغّل workflow باسم **Build Android APK**. سيظهر APK كملف Artifact.

## ملاحظات مهمة

- استخدم التطبيق فقط للمحتوى الذي تملكه أو لديك إذن صريح بتنزيله.
- التطبيق لا يتجاوز DRM ولا يفتح محتوى محميًا أو خاصًا.
- قد تتغير بعض المواقع؛ استخدم زر تحديث المحرك عند ظهور خطأ استخراج.
- بعض المواقع التي تتطلب تسجيل دخول لن تعمل من دون دعم cookies، وهو غير مفعّل في هذا الإصدار.
- مكتبة `youtubedl-android` مرخصة GPL-3.0؛ لذلك المشروع موزع تحت GPL-3.0 أيضًا.
- المكتبات الأصلية تجعل حجم APK كبيرًا نسبيًا.
- دعم أجهزة 16KB memory pages يعتمد على حزم المكتبة الأصلية المستخدمة؛ اختبر التطبيق على الأجهزة المستهدفة قبل النشر الواسع.
