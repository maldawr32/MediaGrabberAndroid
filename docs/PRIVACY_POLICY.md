# Privacy Policy — MediaGrabber

Effective date: 2026-09-04

MediaGrabber is designed to perform media downloads and local file selection on the user's device.

## Data collection

The current version does not require an account and does not include advertising, analytics, or tracking SDKs. The developer does not intentionally collect personal information through the app.

## Network activity

When the user starts a download, Android's system DownloadManager connects to the HTTPS address entered by the user. The destination server may process information normally associated with an internet request, such as the user's IP address, according to that server's own privacy policy.

## Local files

When the user chooses a local video, Android's system document picker grants the app access only to the selected item. The app does not upload that video to a developer-operated server.

## Responsible use

Users should download only content they own or are authorized to download. MediaGrabber does not provide YouTube video extraction or functionality intended to bypass third-party platform protections.

## Changes

If future versions add analytics, advertising, cloud services, accounts, or other data processing, this policy and the Google Play Data Safety declaration must be updated before release.
